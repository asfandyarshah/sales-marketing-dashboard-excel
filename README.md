Sales & Marketing Campaign Dashboard (Excel)

An Excel workbook that analyses sales and compares marketing campaign performance. Everything on the dashboard is formula-driven, so it updates when the data changes.

Note: all data is made-up sample data for demonstration. Replace it with real data to use the workbook.

Sheets

	•	README: how to use the workbook, assumptions, and colour key
	•	Dashboard: KPIs, revenue by product, region, and month, campaign ROI, and 3 charts
	•	Sales: 150 sample orders (Month and Revenue calculate automatically)
	•	Campaigns: spend, impressions, and clicks per campaign, with calculated orders, revenue, click-through rate, cost per order, and ROI

How it works

	•	SUMIFS and COUNTIFS pull totals from the Sales sheet
	•	IFERROR handles divide-by-zero cases
	•	Conditional formatting and data bars highlight strong and weak results
	•	Blue text marks cells you can edit; black text is formulas

Assumptions

	•	Revenue = Units x Unit Price
	•	ROI = (Revenue - Spend) / Spend
	•	Each order is attributed to one campaign
	•	Overall ROI includes organic revenue, so it overstates what the ads alone earned

Skills shown

Excel formulas, charts, conditional formatting, data layout, documentation.
